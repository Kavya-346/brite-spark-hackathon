# AI Usage

AI tools were used during the development of this project.

## Areas where AI was used

AI assistance was used for:

- Project scaffolding and code structure.
- Debugging Python, Flask, FAISS, and import-path issues.
- Retrieval and grounding logic.
- Date-aware amendment handling.
- Cross-reference and amendment-only clause handling.
- Citation validation.
- Test-case generation and debugging.
- UI implementation and refinement.
- README and DECISIONS.md drafting.
- Reviewing errors and improving refusal behavior.

## Verification

AI-generated suggestions were reviewed, adapted, and tested before being included in the repository.

The submitted implementation was tested using the project's evaluation suite and additional date-sensitive and refusal tests.

The participant is responsible for understanding the submitted implementation and can explain the retrieval, grounding, citation validation, amendment handling, and refusal logic.

## Important limitation

AI assistance was used as a development tool. It was not treated as an authority for policy content.

Policy answers are generated only from the supplied synthetic policy corpus and amendment information.
